## G — Interpretation

A model can show higher basic WER when it verbalizes numbers that the reference writes as digits (or vice versa). After `pl_wer_normalized_v1`, those formatting mismatches no longer inflate WER, so normalized WER better approximates recognition of spoken content for the supported equivalences.

The normalizer is **not** a semantic understanding system: it applies deterministic, versioned surface rules. Homophones, negations, wrong quantities, and brand misspellings remain errors.

## H — Limitations

- N = 1 smoke recording.
- Manually scripted / read speech.
- Possible read-speech vs reference discrepancies; reference not independently verified against audio in this pipeline.
- Polish morphology remains only partially covered (nominative cardinals; year ordinals collapse case).
- Some homophones are acoustically indistinguishable.
- This sample was used while developing normalization rules → **not** an independent held-out benchmark.
- New normalizer performance must be tested on unseen data.
- No confidence intervals or significance claims from one clip.
